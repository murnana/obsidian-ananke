# Dev Container マニュアル

このマニュアルでは、Ananke プロジェクトで使用している Dev Container について説明します。

## Dev Container とは

Dev Container（Development Container）は、Docker コンテナを使って開発環境を構築する仕組みです。

通常、プロジェクトに参加するときは「Node.js をインストールして、VS Code の拡張機能を入れて、設定を合わせて...」といった準備が必要です。Dev Container を使うと、これらの環境構築がすべて自動化されます。

### メリット

- **環境の統一**: 全員が同じ OS・ツール・設定で開発できるため、「自分の環境では動くのに...」という問題が起きません
- **セットアップの簡単さ**: 数クリックで開発環境が整います
- **ホスト環境を汚さない**: すべてコンテナ内で完結するため、PC 本体の環境に影響しません
- **再現性**: コンテナを削除して作り直せば、いつでもクリーンな環境に戻せます

### 仕組みの概要

```
┌─────────────────────────────────────────────┐
│  あなたの PC（ホスト）                        │
│                                             │
│  ┌──────────────────────────────────────┐   │
│  │  VS Code                            │   │
│  │  ┌──────────────────────────────┐    │   │
│  │  │  Docker コンテナ             │    │   │
│  │  │                              │    │   │
│  │  │  - Node.js 22                │    │   │
│  │  │  - TypeScript                │    │   │
│  │  │  - GitHub CLI                │    │   │
│  │  │  - Claude Code               │    │   │
│  │  │  - プロジェクトのソースコード  │    │   │
│  │  │                              │    │   │
│  │  └──────────────────────────────┘    │   │
│  └──────────────────────────────────────┘   │
└─────────────────────────────────────────────┘
```

VS Code がコンテナの中に接続して、あたかもコンテナ内で直接作業しているかのように開発できます。
