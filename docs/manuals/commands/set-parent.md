# Set parent task

開いているタスクの親タスクを設定します。

## 利用条件

タスクノート上でのみ使えます。

## 手順

1. 子にしたいタスクのノートを開きます。
2. **Set parent task** を実行します。
3. 一覧から親にするタスクを選びます。入力で絞り込めます（プレースホルダー: `Choose the parent task`）。

## 挙動

- 候補は、開いているタスクと同じ Base のタスクフォルダ内のノートから、自分自身を除いたものです。archive フォルダ内のタスクも含まれます。
- `parent` プロパティが親タスクへのリンク（`[[タスク名]]`）で置き換えられます。すでに親が設定されている場合は上書きされます。
- 親子関係に循環がないかの検査は行われません。
