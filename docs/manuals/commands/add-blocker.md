# Add blocking task

開いているタスクの前に終わらせるべきタスク（blocker）を追加します。

## 利用条件

タスクノート上でのみ使えます。

## 手順

1. ブロックされる側のタスクのノートを開きます。
2. **Add blocking task** を実行します。
3. 一覧から、先に終わらせるタスクを選びます（プレースホルダー: `Choose a task that must finish first`）。

## 挙動

- 候補は、開いているタスクと同じ Base のタスクフォルダ内のノートから、自分自身を除いたものです。archive フォルダ内のタスクも含まれます。
- 選んだタスクへのリンク（`[[タスク名]]`）が `blocked-by` プロパティのリストの末尾に追加されます。
- すでに同じタスクが登録されている場合は追加されず、`<タスク名> is already a blocker.` と通知されます。
- 追加済みのリンクの解除はこのコマンドではできません。ノートの `blocked-by` プロパティを直接編集してください。
