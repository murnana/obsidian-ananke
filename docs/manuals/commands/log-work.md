# Log work manually

タイマーを使わず、作業時間と内容を手入力で記録します。

## 利用条件

タスクノート上でのみ使えます。

## 手順

1. 記録したいタスクのノートを開きます。
2. **Log work manually** を実行します。
3. `Log work: <タスク名>` ダイアログで項目を入力します。

   | 項目 | 必須 | 説明 |
   |---|---|---|
   | **Date** | 必須 | 作業した日。初期値は今日。 |
   | **Start time** | - | 開始時刻。入力した場合のみ、見出しに時間帯が入ります。 |
   | **Hours** | 必須 | 作業時間（小数の時間。例: `1.5`）。0 より大きい値。 |
   | **Memo** | - | 作業内容。Markdown としてノートに保存されます。 |

4. **Save** を選択するか、Ctrl/Cmd+Enter を押します。

## 保存される内容

ノートの `## Work log` セクションの末尾に、次のような記録が追加されます。セクションがなければ、ノートの末尾に作成されます。

**Start time を入力した場合**（終了時刻は開始時刻 + 作業時間）:

```markdown
### 2026-10-21 09:30–11:00 (1.5h)
メモの内容
```

**Start time を空にした場合**:

```markdown
### 2026-10-21 (1.5h)
メモの内容
```

あわせて、`logged` プロパティに作業時間が加算されます（小数第 2 位に丸め）。

## 入力の検証

- **Hours** が数値でない、または 0 以下の場合は `Enter the hours worked.` と通知されます。
- **Date** が日付として不正な場合は `Enter a valid date.` と通知されます。
- 保存に失敗した場合は `Failed to log work.` と通知され、ダイアログは開いたままです。
