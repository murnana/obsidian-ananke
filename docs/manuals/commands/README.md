# コマンド一覧

コマンドパレット（Ctrl/Cmd+P）で `Ananke` と入力すると絞り込めます。ホットキーは既定では割り当てられていません。**Settings → Hotkeys** で割り当てられます。

「タスクノート上」とは、登録済みタスクフォルダ内の Markdown ノートを開いている状態を指します。

| コマンド | 利用条件 | ページ |
|---|---|---|
| **Register a base** | 常時 | [register-base.md](register-base.md) |
| **Create task** | 常時（Base が未登録なら通知） | [create-task.md](create-task.md) |
| **Create subtask of current task** | タスクノート上 | [create-subtask.md](create-subtask.md) |
| **Fill missing task properties** | 常時 | [fill-missing-properties.md](fill-missing-properties.md) |
| **Enforce base definitions** | 常時 | [enforce-base-definitions.md](enforce-base-definitions.md) |
