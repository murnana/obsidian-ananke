# Fill missing task properties

タスクフォルダ内のすべてのノートについて、不足しているタスクのプロパティを補います。

## 利用条件

常時使えます。

## 手順

1. **Fill missing task properties** を実行します。
2. 完了すると `Updated <件数> task(s).` と通知されます。

## 挙動

- 登録済みのすべてのタスクフォルダ（archive フォルダを含む）が対象です。
- 不足しているプロパティだけを[既定値](../concepts.md#タスクのプロパティ)で追加します。**すでにある値は上書きしません。**
- すべてのプロパティが揃っているノートは変更されません（件数にも含まれません）。

## 自動補完

このコマンドを実行しなくても、タスクフォルダ内に**ノートが作成された**とき、または**ノートが移動・名前変更された**ときに、そのノートのプロパティは自動で補われます。このコマンドは、次のような場合に使います。

- Ananke の導入前から存在するノートを、タスクとして扱いたいとき
- 登録時点で、すでにタスクフォルダにあったノートを補いたいとき
