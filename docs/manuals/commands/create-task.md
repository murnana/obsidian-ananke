# Create task

新しいタスクのノートを、登録したタスクフォルダに作成します。

## 利用条件

常時使えます。Base が 1 つも登録されていない場合は `Register a base first.` と通知されます。

タスクノート上で実行した場合は、そのタスクと同じ Base が選ばれます。それ以外の場合は、最初に登録した Base が選ばれます。

## 手順

1. **Create task** を実行します。
2. 項目を入力します。

   | 項目 | 必須 | 説明 |
   |---|---|---|
   | **Title** | 必須 | タスク名。ノートのファイル名になります。 |
   | **Base** | - | Base を 2 つ以上登録している場合のみ表示。作成先を選びます。 |
   | **Estimate** | - | 見積もり時間（時間単位、0 以上、0.25 刻み）。 |
   | **Due date** | - | 期日（日付）。 |
   | **Deadline** | - | 締め切り。日付、または日付と時刻。例: `2026-01-31 18:00` |

3. **Create** を選択するか、Enter キーを押します。

作成されたノートは、そのまま開きます。

## 作成されるノート

frontmatter に[タスクのプロパティ](../concepts.md#タスクのプロパティ)がすべて入った状態で作成されます。未入力の項目は既定値になります（`status` は `Not started`、`logged` は `0`）。

## 入力の検証

次の場合は作成されず、通知が表示されます。

- Title が空
- Estimate が数値でない、または負の値
- Due date が日付として不正
- Deadline が日付、または日付と時刻として不正（日付と時刻の間は空白でも `T` でも可）

## 注意点

- ファイル名には使えない文字 `\ / : * ? " < > | # ^ [ ]` が Title から取り除かれます。
- 同名のノートがすでにある場合は、`タイトル 1`、`タイトル 2` のように連番が付きます。
