# Register a base

Base ファイルとタスクフォルダの組を登録します。登録すると、その場でフォルダと Base ファイルが整えられます。

## 利用条件

常時使えます。**Settings → Ananke** の **Register** ボタンからも同じダイアログが開きます。

## 手順

1. **Register a base** を実行します。
2. 次の項目を入力します。

   | 項目 | 説明 |
   |---|---|
   | **Base file** | 既存の `.base` ファイル、または新規作成するパス。入力欄では既存の Base ファイルが候補表示されます。例: `Projects/Foo/Foo.base` |
   | **Task folder** | タスクを置くフォルダ。入力欄ではフォルダが候補表示されます。空欄の場合は Base ファイルと同じ階層の `tasks`（Base がルート直下なら `tasks`）になります。 |

3. **Register** を選択します。

## 登録時に行われること

- タスクフォルダと、その中の `archive` フォルダを作成します（既存なら何もしません）。
- Base ファイルがなければ作成します。
- Base ファイルに Ananke の管理内容（タスクフォルダの絞り込み、プロパティの表示名、**Active** / **Archive** ビュー）を書き込みます。→ [Enforce base definitions](enforce-base-definitions.md)

完了すると `Registered <path>.` と通知されます。

## 入力の検証

- パスの末尾が `.base` でなければ、自動で付与されます。
- 次の場合は登録できず、通知が表示されます。
  - Base ファイルが空欄、またはルートを指している
  - 同じ Base ファイルがすでに登録されている
  - タスクフォルダが Vault のルートである
  - タスクフォルダが、登録済みのタスクフォルダと同じ、またはその内側・外側にある
  - Base ファイルがタスクフォルダの中にある

## 注意点

- 既存の Base ファイルを指定した場合、その内容は保持され、Ananke の管理部分だけが追加・更新されます。YAML として解釈できないファイルは書き換えられません。
- 登録の解除は [設定](../settings.md) から行います。
