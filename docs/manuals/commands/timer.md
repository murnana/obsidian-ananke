# Start timer / Stop timer

タスクの作業時間を計測し、停止時に作業ログとして保存します。

## 利用条件

| コマンド | 表示される条件 |
|---|---|
| **Start timer** | タスクノートを開いていて、かつ他のタイマーが動いていない |
| **Stop timer** | タイマーが動いている（どのノートを開いていても可） |

タイマーは同時に 1 つだけ動かせます。

## 手順

### 開始する

1. 計測したいタスクのノートを開きます。
2. **Start timer** を実行します。

開始すると、ステータスバーに `⏱ <タスク名> h:mm:ss` が表示され、1 秒ごとに更新されます。

### 停止して記録する

1. **Stop timer** を実行します。ステータスバーのタイマー表示を選択しても停止できます。
2. `Log work: <タスク名>` ダイアログが開きます。計測した開始日時・終了時刻・時間が表示されます。
3. **Memo** に作業内容を Markdown で入力します（任意）。
4. **Save** を選択するか、Ctrl/Cmd+Enter を押します。

保存すると、ノートの `## Work log` に記録が追加され、`logged` に時間が加算されます。書式は[作業ログの書式](../concepts.md#作業ログの書式)を参照してください。

計測結果を残さず終了したいときは **Discard** を選択します。タイマーは停止し、何も記録されません。

## 挙動

- 開始時、タスクの `status` が `Not started`（または未設定）なら `Doing` に変わります。`Done` や `Omit` などは変更されません。
- 開始時刻は設定（`data.json`）に保存されるため、Obsidian を再起動してもタイマーは動き続けます。
- ダイアログを **Save** または **Discard** せずに閉じた場合、タイマーは停止しません。もう一度 **Stop timer** を実行してください。
- 計測中にタスクノートの名前を変更・移動しても、タイマーは追従します。
- 計測中のタスクノートが削除された場合、停止時に `The timed task <path> no longer exists; the timer was discarded.` と通知され、タイマーは破棄されます。
- すでにタイマーが動いている状態で別のタスクから開始しようとすると、`A timer is already running for <task>. Stop it first.` と通知されます。
