# 設定

Ananke プラグインの設定項目について説明します。

## 設定画面の開き方

1. Obsidian の **設定**（左下の歯車アイコン、または `Ctrl+,` / `Cmd+,`）を開く
2. 左側のメニューから「**Ananke**」を選択

## 設定項目

### タスクフォルダー

| 項目 | 内容 |
| --- | --- |
| 設定名 | タスクフォルダー |
| デフォルト値 | `ananke-tasks` |
| 説明 | タスクが保存されるフォルダー名を指定します |

タスクデータの保存先となるフォルダー名を設定します。保管庫内のルートからの相対パスで指定してください。

#### 変更手順

1. 設定画面で「タスクフォルダー」のテキスト欄を見つける
2. フォルダー名を入力する（例: `my-tasks`）
3. テキスト欄からフォーカスを外すと、設定が自動的に保存されます

> **注意:** 現在のバージョン（v0.0.1）では、この設定は保存されますが、まだタスク管理機能が実装されていないため実際のフォルダー操作は行われません。

## 設定データの保存場所

設定は以下の場所に自動保存されます:

```
{あなたの保管庫}/.obsidian/plugins/murnana-ananke/data.json
```

通常はこのファイルを直接編集する必要はありません。
