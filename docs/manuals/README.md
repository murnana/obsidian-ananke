# Ananke 使用マニュアル

Ananke は、タスクの見積もり・記録・確認を Obsidian 上で行うためのプラグインです。タスクを 1 ノート 1 タスクで管理し、Obsidian の Base（`.base` ファイル）で一覧表示します。

## できること

- Base とタスクフォルダを登録し、タスク一覧（Active / Archive ビュー）を自動で整える
- 見積もり・期日・締め切り付きでタスクやサブタスクを作成する
- 親タスクや、先に終わらせるべきタスク（blocker）を設定する
- タイマーまたは手入力で作業時間を記録し、ノート本文に作業ログを残す
- 終わったタスクをアーカイブする

## 表記について

- コマンドは、コマンドパレットでは `Ananke: <コマンド名>` の形で表示されます。このマニュアルでは **コマンド名** のみ記載します。
- 画面上のボタンや項目名は、実際の表示どおり英語で **太字** にしています。
