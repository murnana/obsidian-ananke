# 基本概念

## Base・タスクフォルダ・archive フォルダ

Ananke は「Base ファイル」と「タスクフォルダ」の組を **登録（registration）** として管理します。

| 用語 | 説明 |
|---|---|
| Base ファイル | タスク一覧を表示する `.base` ファイル。 |
| タスクフォルダ | タスクのノートを置くフォルダ。この中の Markdown ノートがタスクとして扱われます。 |
| archive フォルダ | タスクフォルダ直下の `archive` フォルダ（例: `tasks/archive`）。アーカイブしたタスクが移動します。 |

- Base ファイルはタスクフォルダの外に置く必要があります。
- 登録同士でタスクフォルダが重なる（同じ、または一方が他方の内側にある）ことはできません。
- 1 つのタスクは、そのノートがあるフォルダによって所属する Base が決まります。
- 複数の Base を登録できます。

## タスクのプロパティ

タスクノートの frontmatter に、次のプロパティが保存されます。Base ではカッコ内の名前で表示されます。

| プロパティ | 表示名 | 既定値 | 説明 |
|---|---|---|---|
| `status` | Status | `Not started` | 状態。`Not started` / `Doing` / `Done` / `Omit` のいずれか。 |
| `due` | Due date | 空 | 着手や完了を予定する日（`YYYY-MM-DD`）。 |
| `deadline` | Deadline | 空 | 締め切り。`YYYY-MM-DD`、または `YYYY-MM-DDTHH:MM`。 |
| `estimate` | Estimate | 空 | 見積もり時間（時間単位）。 |
| `logged` | Logging time | `0` | 記録済みの作業時間の合計（時間単位）。 |
| `parent` | Parent | 空 | 親タスクへのリンク（`[[タスク名]]`）。 |
| `blocked-by` | Blocked by | 空のリスト | 先に終わらせるべきタスクへのリンクのリスト。 |

- タスクフォルダに作成・移動されたノートに不足しているプロパティは、自動的に補われます。既存の値は上書きされません。→ [Fill missing task properties](commands/fill-missing-properties.md)
- Ananke が `status` を自動で変更するのは、タイマー開始時の `Not started` → `Doing` のみです。それ以外の変更は手動で行います。

## 作業ログの書式

作業の記録は、タスクノート本文の `## Work log` セクションの末尾に追加されます。セクションがなければ、ノートの末尾に作成されます。

時刻あり（タイマー、または手入力で開始時刻を指定）:

```markdown
## Work log

### 2026-10-21 09:30–11:00 (1.5h)
調査と設計を行った。
```

時刻なし（手入力で開始時刻を空にした場合）:

```markdown
### 2026-10-21 (2h)
メモ
```

- 終了時刻は「開始時刻 + 作業時間」で計算されます。
- メモが空の場合は見出しのみが追加されます。
- 作業時間は小数第 2 位までに丸められ、`logged` に加算されます。
- `## Work log` セクションは、次のレベル 1 または 2 の見出しの手前までです。セクションの後ろに別の見出しがあっても、その手前に追加されます。
