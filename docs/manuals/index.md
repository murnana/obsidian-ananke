# Ananke プラグイン ユーザーマニュアル

Ananke は、Obsidian 上でタスクの見積もり・記録・振り返りを行うためのプラグインです。

> **注意:** このプラグインは現在開発初期段階（v0.0.1）です。現時点ではサンプル機能のみが含まれており、タスク管理機能は今後実装される予定です。

## 機能一覧

| 機能 | 状態 | 説明 |
| --- | --- | --- |
| リボンアイコン | サンプル | サイドバーにアイコンを追加し、クリックで通知を表示 |
| ステータスバー | サンプル | 画面下部にテキストを表示 |
| コマンド（3種類） | サンプル | コマンドパレットから実行できるアクション |
| 設定タブ | 実装済み | タスクフォルダーの指定が可能 |
| 多言語対応 | 実装済み | 日本語をデフォルト言語としてサポート |
