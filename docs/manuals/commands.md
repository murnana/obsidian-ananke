# コマンド

Ananke プラグインが提供するコマンドと UI 要素について説明します。

> **注意:** 現在のバージョン（v0.0.1）では、すべてのコマンドはサンプル実装です。今後のアップデートでタスク管理に関する本格的な機能に置き換わる予定です。

## コマンドパレットからの実行

Obsidian のコマンドパレット（`Ctrl+P` / `Cmd+P`）を開き、コマンド名を入力して実行できます。

## コマンド一覧

### Open sample modal (simple)

| 項目 | 内容 |
| --- | --- |
| コマンド ID | `murnana-ananke:open-sample-modal-simple` |
| 利用可能条件 | 常に利用可能 |
| 動作 | モーダルダイアログを表示します |

コマンドパレットから実行すると、サンプルのモーダルダイアログが開きます。

### Sample editor command

| 項目 | 内容 |
| --- | --- |
| コマンド ID | `murnana-ananke:sample-editor-command` |
| 利用可能条件 | エディターが開いているとき |
| 動作 | エディター内で選択中のテキストを置換します |

エディターでテキストを選択した状態でこのコマンドを実行すると、選択範囲が「Sample Editor Command」というテキストに置き換わります。

### Open sample modal (complex)

| 項目 | 内容 |
| --- | --- |
| コマンド ID | `murnana-ananke:open-sample-modal-complex` |
| 利用可能条件 | マークダウンファイルを開いているとき |
| 動作 | モーダルダイアログを表示します |

マークダウンファイルを開いている場合のみ、コマンドパレットに表示されます。実行するとサンプルのモーダルダイアログが開きます。

## リボンアイコン

プラグインを有効にすると、左側のサイドバー（リボン）にサイコロのアイコンが追加されます。

| 項目 | 内容 |
| --- | --- |
| アイコン | サイコロ（dice） |
| ツールチップ | Sample Plugin |
| 動作 | クリックすると「This is a notice!」という通知を表示 |

## ステータスバー

画面下部のステータスバーに「Status Bar Text」というテキストが表示されます。現在は固定テキストのみで、動的な情報は表示されません。
